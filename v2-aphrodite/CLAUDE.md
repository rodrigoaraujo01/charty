# Charty 2.0 Site

This is Charty's 1.0 website.

## Overview

Charty is an iOS app that allows you to create charts directly from Apple's Shortcuts app.

## About this project

This is a static website hosted as a github page.
The address is https://chartyios.app

## About this update

This new update will feature:
- A completely rebuilt and redesigned app in SwiftUI using new libraries such as SwiftCharts and AppIntents which will make it a lot easier to update the app in the future;
- Fixes for major complaints like the widgets not updating;
- Improved styling capabilities like new color themes and applying gradients to series;
- New examples with detailed instructions of what each shortcuts' action is used for. 

This new version won't be localized in the first moment (effectively dropping portuguese, french and spanish localizations) and also won't have video tutorials. 

Additionally, Charty operated in a freemium model since its launch with a limited free tier and a one time unlock that costed $4.99. From this version on, Charty will become subscription based with monthly ($0.99) and yearly ($9.99) tiers. 

Users that bought the old $4.99 unlock will have access to the entirety of the redesigned app, and will keep having access to everything the app does on 2.0. 

Starting on 2.1, there'll be new actions and features (such as mathematical regressions) that'll require the subscription tier.
